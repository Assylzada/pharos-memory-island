# Pharos: Interactive Memory Island

## 1. Project Overview

Pharos is a gamified mobile application designed to help users preserve, visualize, organize, and revisit personal memories through an interactive virtual island.

Saved memories are represented as meaningful elements within the island. As users preserve memories, the island can gradually develop through a defined progression mechanism.

## 2. Problem Statement

Personal memories are often distributed across photographs, notes, messages, and separate applications. Conventional storage methods may preserve information but offer limited opportunities to explore memories through a connected and interactive visual environment.

Pharos investigates whether an interactive virtual island can provide an engaging way to organize and revisit personal memories.

## 3. Project Goal

To design, develop, and evaluate a gamified mobile application for preserving personal memories through an interactive virtual island.

## 4. Objectives

- Review relevant research and existing memory-preservation applications.
- Identify user needs and define functional and non-functional requirements.
- Compare candidate technologies and document the selected stack.
- Design the application architecture and user experience.
- Create a prototype of the main memory-management workflow.
- Implement and verify the core features.
- Evaluate usability and perceived usefulness.

## 5. Target Users

The initial target audience consists of individuals who want to preserve personal experiences and revisit them through a visual and interactive environment.

## 6. Initial Feature Set

- Create and edit personal memories.
- Save and retrieve memory content.
- Represent memories as interactive island elements.
- Open the corresponding memory by selecting an island element.
- Display progress through a defined gamification mechanism.
- Protect the privacy of stored personal information.

The final feature set will be confirmed through requirements analysis.

## 7. Project Scope

### In Scope
- Mobile application design and prototyping.
- Personal memory management.
- Virtual island visualization.
- Basic gamification.
- Data persistence.
- Functional verification and usability evaluation.

### Out of Scope for the Initial Version
- Public social networking.
- Multiplayer interactions.
- Advanced AI-generated memory reconstruction.
- Augmented reality.
- Clinical or therapeutic functionality.
